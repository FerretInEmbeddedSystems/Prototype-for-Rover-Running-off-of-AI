# Requirements
This is a file containing all the information about the hardware products and so on that we are going to be using.

## Hardware
  We have six components for our system that we will be using.
    1)  Microcontroller     -  Arduino Uno 4
    2)  Companion Computer  -  Raspberry Pi
    3)  Rover Chasis & Two DC Gear Motors - TBD
    4)  Dual motor driver   — TB6612FNG or suitably rated equivalent
    5)  Distance sensor     — HC-SR04 or compatible alternative
    6)  Camera compatible with the companion computer
